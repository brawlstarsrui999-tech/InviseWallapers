# Wallapers

Небольшое Android-приложение с локальной коллекцией абстрактных обоев. В проекте нет доступа к списку установленных приложений: Wallapers не клонирует, не скрывает и не запускает сторонние приложения.

## Возможности

- четыре нарисованные прямо в приложении темы обоев;
- выбор избранного и сохранение последнего выбора локально;
- установка выбранного изображения на главный экран через системный `WallpaperManager`;
- настройки тактильного отклика и подсказки на главной;
- прозрачные правила использования и переход к штатным настройкам Android.

## Открыть в Android Studio

1. Откройте в Android Studio папку `InviseWallapers`.
2. Дождитесь Gradle Sync и установите Android SDK Platform 35, если Studio предложит.
3. Запустите конфигурацию `app` на эмуляторе или устройстве с Android 7.0 (API 24) или новее.

Требуются JDK 17 и Gradle 8.9 (Gradle Wrapper настроен на 8.9). Сборка в текущей рабочей среде не запускалась: здесь нет установленного JDK и Android SDK.
