# Wallapers

Android-приложение с локальной коллекцией обоев и созданием отдельных экземпляров приложений через управляемый рабочий профиль Android.

## Возможности клонирования

- Android показывает список установленных приложений с обычной иконкой запуска (системные приложения без обновления исключены).
- Пользователь выбирает приложение, а Android передаёт в рабочий профиль только его имя пакета через отдельный cross-profile intent.
- В рабочем профиле пользователь подтверждает установку. `DevicePolicyManager.installExistingPackage` устанавливает тот же пакет как отдельный экземпляр с независимыми данными и аккаунтом.
- Копии появляются в отдельном экране «Мои приложения» внутри Wallapers рабочего профиля и запускаются кнопкой «Открыть».
- Копии не устанавливаются в личный профиль. Android может показывать их в отдельной системной вкладке рабочего профиля и настройках; скрытия от системы нет.

Оригинальное приложение должно быть установлено на телефоне и разрешать установку в рабочем профиле. Приложения без обычной иконки запуска, некоторые банковские приложения и ограничения производителя/администратора могут помешать копированию. Wallapers не использует `QUERY_ALL_PACKAGES`: видимость ограничена установленными приложениями с launcher-активностью. Приложение не читает содержимое данных, сообщения или пароли сторонних приложений.

## Другие функции

- четыре абстрактные темы обоев, нарисованные на устройстве;
- установка выбранных обоев на главный экран;
- локальное избранное, настройка тактильного отклика и подсказок;
- запуск системного мастера создания рабочего профиля Android.

## Открыть в Android Studio

1. Откройте в Android Studio папку `InviseWallapers`.
2. Дождитесь Gradle Sync и установите Android SDK Platform 35, если Studio предложит.
3. Запустите конфигурацию `app` на устройстве с Android 7.0 (API 24) или новее.
4. Создайте рабочий профиль и подтвердите системный мастер. В обычном Wallapers выберите приложение, нажмите «Клонировать» и в системном выборе укажите Wallapers с отметкой портфеля.

Поддержка рабочего профиля зависит от версии Android, модели телефона и политик устройства. Требуются JDK 17 и Gradle 8.9 (Gradle Wrapper настроен на 8.9). Сборка в текущей рабочей среде не запускалась: здесь нет установленного JDK и Android SDK.
