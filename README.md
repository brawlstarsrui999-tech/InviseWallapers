# Wallapers

Android-приложение с локальной коллекцией абстрактных обоев и прозрачной настройкой второго экземпляра социальных приложений через управляемый рабочий профиль Android.

## Возможности

- четыре абстрактные темы обоев, нарисованные на устройстве;
- установка выбранных обоев на главный экран;
- локальное избранное, настройка тактильного отклика и подсказок;
- запуск системного мастера создания рабочего профиля Android;
- установка отдельного экземпляра выбранного поддерживаемого приложения в этот профиль через `DevicePolicyManager.installExistingPackage`.

Поддерживаемый каталог сейчас включает Telegram, Telegram X, WhatsApp, WhatsApp Business, Instagram, Facebook, X, Snapchat, Signal, Discord, TikTok и VK. Оригинальное приложение должно быть установлено на телефоне. Новая копия имеет отдельные данные и аккаунт; Android показывает её в рабочем профиле с отметкой портфеля. Копии не скрываются из системных настроек. Создание профиля и установка каждого приложения требуют явного подтверждения пользователя.

Настройка рабочего профиля доступна не на всех устройствах: её может запретить версия Android, производитель или администратор устройства. В таком случае приложение покажет сообщение, а не будет пытаться обходить ограничение. Wallapers не читает данные, сообщения или пароли сторонних приложений.

## Открыть в Android Studio

1. Откройте в Android Studio папку `InviseWallapers`.
2. Дождитесь Gradle Sync и установите Android SDK Platform 35, если Studio предложит.
3. Запустите конфигурацию `app` на устройстве с Android 7.0 (API 24) или новее.
4. Для создания второго экземпляра откройте в приложении настройку рабочего профиля и подтвердите системный мастер. Затем запустите Wallapers из рабочего профиля и выберите приложение.

Требуются JDK 17 и Gradle 8.9 (Gradle Wrapper настроен на 8.9). Сборка в текущей рабочей среде не запускалась: здесь нет установленного JDK и Android SDK.
